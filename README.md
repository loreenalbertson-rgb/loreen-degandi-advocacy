# Loreen DeGandi | Independent Patient Advocate

A soft, professional, responsive one-page website for independent patient advocacy.

## Files
- `index.html` — page structure and content
- `styles.css` — sage, light blue, dusty rose, cream design system
- `script.js` — mobile navigation and current year

## Before publishing
1. Create a free Formspree form (or use another secure contact method).
2. In `index.html`, replace:
   `https://formspree.io/f/REPLACE_WITH_YOUR_FORM_ID`
   with your real form endpoint.
3. Review the wording in the About section and personalize it further if desired.
4. Publish through GitHub Pages from the main branch.

## Important
This site intentionally describes services as nonclinical advocacy, organization, research, preparation, and navigation support. Do not add credentials or protected professional titles unless they have actually been earned and can be used lawfully.
