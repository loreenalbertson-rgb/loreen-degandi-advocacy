# Loreen DeGandi | Independent Patient Advocate

A gentle, responsive static website for Loreen DeGandi's independent patient advocacy work.

## Pages

- `index.html` — main advocacy website
- `intake.html` — Request Volunteer Advocacy Support intake page
- `styles.css` — shared responsive styling
- `script.js` — mobile navigation, footer year, and intake-to-email helper

## Contact

Advocacy email: `loreendegandi.advocacy@outlook.com`

## Intake form behavior

The intake form is intentionally front-end only. When submitted, it opens the visitor's email application with a prepared message addressed to the advocacy email. The site itself does not store form responses.

The form also asks visitors not to send highly sensitive medical or identifying information through ordinary email.

## GitHub Pages

Upload all four website files to the repository root and publish from the `main` branch / root folder in GitHub Pages.
