Loreen DeGandi Patient Advocacy Website Refresh

FILES TO UPLOAD / REPLACE
1. Replace index.html with the new index.html.
2. Add home-refresh.css to the repository root.
3. Keep the existing loreen-headshot.png file OR replace it with your preferred long-hair headshot using the exact same filename: loreen-headshot.png.
4. Keep the existing script.js, about.html, and intake.html files.

WHY THIS IS SAFE TO ADD
- The refreshed homepage uses its own stylesheet (home-refresh.css), so your existing about.html and intake.html pages can keep using the original styles.css without being redesigned accidentally.
- The homepage still links to about.html and intake.html.
- The existing mobile navigation/current-year script remains compatible.

IMPORTANT HEADSHOT NOTE
The included preview copy uses the current public loreen-headshot.png from your GitHub repository. If you want the longer-hair photo, replace only loreen-headshot.png in GitHub with that image; the page layout will automatically use it.

GITHUB PAGES
After committing the files to the main branch, GitHub Pages should update automatically. Browser caching may take a minute; a hard refresh can help.
